# 외부 에셋 크레딧

이 프로젝트는 아래 외부 에셋을 사용합니다. 원본 파일은 `Assets/90.ExternalAssets/<분류>/<팩>/`에 있고 **수정하지 않습니다**.

- **저장소 포함**: CC0 또는 CC BY 라이선스로 재배포가 허용된 팩.
- **저장소 제외**: 재배포가 금지됐거나 라이선스를 확인하지 못한 팩. 클론한 뒤 아래 링크에서 직접 받아 표의 경로에 넣으세요. 무엇을 넣는지는 표의 "넣는 내용"을 따릅니다.
